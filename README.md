# CMPM 121 D1 Project

Sushi clicker-Incremental Game
Sushi Clicker is a simple incremental (idle) game where you sell sushi to earn currency, purchase upgrades, and increase automatic production.
Inspired by Cookie Clicker but themed around a friendly sushi shop.

You start with only your hands — clicking to “sell sushi” — but can eventually hire helpers, build machines, unlock mystical scrolls, and trigger rare Golden Sushi events that massively boost profits.

-Features

Click to generate sushi

Passive sushi generation from upgrades

Animated sushi shop background

Golden Sushi “lucky bonus” (appears only after unlocking the upgrade)

Upgrade items:

Sous Chef Helper

Conveyor Belt

Robot Sushi Machine

Ancient Sushi Scroll

Wasabi Turbo Mixer

-How to Run

Open the project folder

Start a local server (VS Code Live Server or python -m http.server)

Open the main HTML file in your browser

Play!
